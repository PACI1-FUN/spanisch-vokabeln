# Spanisch Vokabeln

Web-App zum Lernen spanischer Vokabeln mit Karteikarten, Quiz und Aussprache.
39 Themen, rund 1200 Wörter, mit Bildern.

## Auf iPhone oder iPad installieren
1. Die Adresse der App in **Safari** öffnen.
2. Unten auf **Teilen** tippen (Quadrat mit Pfeil nach oben).
3. **Zum Home-Bildschirm** wählen und **Hinzufügen** tippen.

Danach startet die App über ihr Symbol im Vollbild und funktioniert auch ohne Internet.
Der Lernfortschritt wird auf jedem Gerät separat gespeichert.

## Dateien
- `index.html` – die ganze App (Vokabeln, Bilder, Karteikarten, Quiz)
- `manifest.webmanifest`, `sw.js` – Web-App-Einstellungen und Offline-Betrieb
- `icon-*.png`, `apple-touch-icon.png` – App-Symbol
